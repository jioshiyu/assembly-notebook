# 经验与坑（全部实测，不是猜的）

## 工具链

1. **fasm 默认按 80386 编码**：`shl bx, 4` → `C1 E3 04`。模拟器按 8086 子集实现时会报"未实现 0xC1"。要 8086 纯指令就用 4 次 `shl bx, 1`（`shared/io.inc` 的 `shl4`/`shr4`）。
2. **`include` 是就地展开**：放在文件开头会让被包含的例程占据 `org 100h` 的入口，程序从 `put_str` 开始跑，几分钟都查不出原因。约定：**include 一律放最后**。
3. **fasm 的 `lea di, label` 非法**，报 `invalid operand`；用 `mov di, label`。
4. **沙箱里子进程不能用管道**：`subprocess.run(capture_output=True)` 直接 `PermissionError`。`shared/fasm.py` 把 fasm 的 stdout 重定向到 `build/*.log` 再读文件。
5. **windows 下 python 在临时目录 mkdir 会被拒**（WinError 5，本机沙箱/DEFENDER 限制），所以测试不要依赖 `tempfile`，构建产物统一落 `build/`。

## 模拟器本身

6. **`jmp/call rel` 的基准是"取完操作数之后的 IP"**：写成 `self.ip = self.ip + self.fetch8()` 会因为求值顺序拿错基准（先算 ip 再取立即数），跳转落到指令中间，症状是"未实现的指令 0x??"。正确写法：先 `rel = self.fetch8()`，再 `self.ip += rel`。
7. **REPE 与 REPNE 的停止条件相反**：`REPE CMPSB`（F3）在 **ZF=0** 时停，`REPNE`（F2）在 **ZF=1** 时停。只判一边会让子串查找永远返回 FOUND。
8. **`JCXZ` 不改 CX**，其余 `LOOP` 家族都要先减再判。
9. 8 位寄存器必须按 **索引** 映射（AL,CL,DL,BL,AH,CH,DH,BH），不能拿名字哈希表直接用 modrm 的 reg 号。
10. `LEA` 要返回**偏移**而不是物理地址——`_ea()` 里顺手记一个 `_last_off` 最省事。

## 判题与用例

11. **用例里的 `expect` 要独立写**（不要拿 ref 生成），否则 ref 错了永远发现不了。本次靠这条抓到 3 处自己写错的期望值（`0F 0F` 的 AAM 结果、`0000 8000` 的取负、作业原题的正负数计数）。
12. **输入必须以换行结尾**：`read_hex8` 靠"读到非十六进制字符"判断 token 结束，输入耗尽时模拟器会抛 `input exhausted`。
13. **空 token 读不出来**：`read_word` 会跳过空白，所以随机生成器至少要给 1 个字符，否则""永远读不到。
14. 边界清单（沿用算法仓库）：0/1 个元素、最大最小值、进位与借位、补码回绕（`0x80000000` 取负还是自己）。

## 原版作业里的问题（写下来当成教材）

15. `1.3` 的 `ADD BX,BX / SBB BX,BX` 用 **CF 当掩码**，只有高字最高位为 1 才能得到 `FFFFh`；一般数要老老实实"取反加一"。
16. `5.2` 演示数据 `'1COOCOO$'` 不含 `'COOL'`，原版实际输出 NOT FOUND。
17. `1.2` 的 AAM 只在乘积低字节 < 100 时是合法 BCD；`0xFF*0xFF` 会得到 `AH=0, AL=1`。


## fasm 与编码方式（第 2 批新增）

18. **fasm 保留字不能当标号**：`display`（汇编期输出指令）、`dup`（重复运算符）都会报 `invalid operand`；改名为 `show_ch` / `is_dup`。
19. **fasm 1.64 支持宏内 `local`**，同一个宏实例化多次安全（`print_hex_word` 用了两次）。
20. **距离 >127 字节时 fasm 自动用 `0F 8x`（Jcc rel16）**——这是 80186+ 编码；同类还有 `push imm`(68/6A)、`shl r,imm`(C1)、`setcc`(0F 9x)、`xlatb`(D7)。模拟器要么支持，要么代码里绕开（`shl4`/`shr4`）。
21. **助记符差异**：fasm 里没有裸 `xlat`，要写 `xlatb`。

## 模拟器第 2 批踩的坑

22. `INT 10h` 分派用"元组包含"时漏了 `AH=02/03/0E`：功能写了但没被分派到，程序跑到光标定位才炸。
23. **`REP` 在 `CX=0` 时一次都不执行**：漏了这条，`CX` 会减成 `FFFF` 跑满 64K 次，症状是"跳进数据区把 ASCII 当指令执行"。
24. **标志位要"立刻取"**：`mov` 不改标志，但 `adc` 会重写 OF/CF；想记录上一条 `add` 的 OF，必须紧跟 `seto`，否则永远读到 0。
25. **原版 `10.3` 的 `CALCFIBO` 在 N=2 时是死循环**：`sub cx,2` 把 CX 变 0，`LOOP` 于是跑 65535 次。
26. **`9.1/9.2` 是 GBK 编码**（不是 UTF-8），`read` 工具会直接报 invalid UTF-8；先 `gb18030` 解码、去掉多余 `
` 再存档。

## DOS 文件 API（第 3 批新增）

27. **句柄从 5 开始**：0–4 是标准设备（CON/AUX/PRN），自己分配的句柄不能占用；模拟器里同样从 5 起分配。
28. **`3Ch` 是"创建并截断"**：已存在的文件会被清空。想追加要先 `3Dh` 打开 + `42h` 定位到末尾（AX=4202h）。
29. **定长记录**（32 字节/条）让"整表覆盖写"变得便宜：插入后 `3Ch` 截断 + `40h` 一次写完即可，不需要临时文件；
   **记录尾部必须补 0**，否则缓冲区里的旧内容会漏进磁盘（第一次实测就踩到了，record 后半段是上一个词的残留）。
30. **文件也能对拍**：`ref.py` 加个 `expected_disk(inp)`，`check.py` 会比较内存虚拟盘的内容——磁盘格式错了立刻红。

## 仓库协作（第 4 批新增）

31. **私有仓库查不了 Actions**：`api.github.com/repos/<owner>/<repo>/actions/runs` 未登录时对私有仓返回 403，
   仓库族索引里要显示成 `private` 而不是 `unknown`（否则会误判成"CI 挂了"）。
32. **每次插入后整表重写**（`3Ch` 截断 + `40h` 写）比原版的"主文件+临时文件交替"简单得多；
   代价是写放大，但课程规模（≤32 条记录）完全可接受，换取的是**文件内容可对拍**。

## 变异测试与外部 oracle（第 5 批新增）

33. **变异测试的"逃逸"不等于 bug，可能是不死代码**：`window-notepad` 里 `inc dh`（不在底部时下移光标）
   永远执行不到——光标只在第 18 行活动，换行走的都是上卷分支。变异后行为不变 → 逃逸。
   这类"逃逸"要人工看一眼再决定补用例还是删死代码。
34. **沙箱里 pip 装不上时，可以自带 wheel**：`pip` 会在自己的解包目录里被拒（Permission denied），
   但 `urllib` 直接下 `.whl` + `zipfile` 解压到 `_vendor/site` 完全可行（见 `tools/vendor_wheel.py`）。
35. **外部 oracle 只覆盖纯控制台题**：`INT 21h` 文件 API 与 `INT 10h` 屏幕在 Unicorn 侧没有 DOS，
   对这类题要显式标 SKIP（不是 FAIL），否则 CI 会把"覆盖不到"误报成"实现错了"。
